GAIT CORRECTION WITH Q-LEARNING

The SpiderPi hexapod consistently veered left due to small mechanical asymmetries that couldn't be corrected by hand. We framed this as a reinforcement learning problem: a Q-learning agent that observes yaw error and selects stride timing adjustments in real time — no manual tuning required.
MAPPING AN UNKNOWN MAZE

Given a completely unknown maze, the robot had to explore every corridor, build a grid map of what it found, and return to its starting position — using only a single sonar sensor and dead-reckoned position estimates. No prior layout, no external localization.
