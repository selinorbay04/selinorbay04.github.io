SEMI-AUTONOMOUS
MAZE GAME

Line-following Robot with Human-in-the-loop

Feb 2024 – Mar 2024
Programmer + Hardware Assembly
Embedded C RF Communication Backtracking MicroBit State Machine

THE SYSTEM

A line-following robot that navigates a maze autonomously but pauses at junctions to ask for direction. The user steers via a handheld micro:bit controller; the robot handles the rest: line tracking, obstacle detection, backtracking, and autonomously retracing the correct path to start once the finish is reached.

ENGINEERING THE BUILD

Architecture Two micro:bit v2s communicating over RF. Robot micro:bit handles all driving logic; controller micro:bit handles wireless input and feedback.
Software Written entirely in C, structured with device-specific include files and separate directories per subsystem.
RF Protocol Custom RF packet protocol for reliable state transfer between controllers. LEDs flag junctions, obstacles, and maze completion.
Backtracking State machine tracks the decision stack at each junction and auto-pops wrong turns on dead ends.
Hardware Datasheet-driven integration: register config for line sensor array, sonar distance sensor, and RF radio.

THE UNEXPECTED FIX

Our backtracking passed every bench test – then misbehaved on the real maze. The robot chassis was casting a shadow on the bottom-mounted line sensors, making them read white surface as black lines at junctions.

Wrong reads → wrong user prompts.

We diagnosed it and mounted white LEDs on the chassis underside as fill lighting. It improved detection – not perfectly, but enough to validate the root cause.

The real lesson: sensor placement is part of the design, not an afterthought.
